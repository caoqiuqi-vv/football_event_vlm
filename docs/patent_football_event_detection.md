# 发明专利技术交底书

## 发明名称

一种基于检测感知空间裁剪与自适应时序采样的足球视频关键事件定位方法及系统

---

## 一、技术领域

本发明属于计算机视觉与视频理解技术领域，具体涉及一种面向远景拍摄足球比赛视频的关键事件（射门、扑救、角球、任意球、点球等）自动检测与定位方法，尤其针对自研全景相机拍摄的球场全景视频中目标尺寸极小、有效信息稀疏的场景。

---

## 二、背景技术与要解决的技术问题

### 2.1 技术背景

足球比赛视频的自动化分析是体育科技领域的重要课题。通过对比赛视频进行关键事件（射门、扑救、定位球等）的自动检测与定位，可以大幅减少人工标注成本，支撑自动集锦生成、战术分析、直播增强等应用。

当前主流方案通常采用深度学习模型对视频片段进行分类，但面临以下核心挑战：

### 2.2 现有技术的不足

**（1）远景拍摄导致的有效信息稀疏问题**

自研全景相机（如Xbotgo系列）拍摄的足球比赛视频通常为远景广角画面，以覆盖尽可能多的球场区域。这导致画面中的关键语义元素——球（直径可能仅3-5像素）、球员（高度约15-30像素）、球门——在整体画面中占比极小。直接将整帧图像缩放到模型输入尺寸后，这些微小目标的细节信息几乎完全丢失，模型难以提取有效的判别特征。

**现有方案缺陷**：传统方法对整帧画面均匀处理，不区分前景/背景区域，大量背景信息（天空、看台、场外区域）不仅无助于事件识别，还会引入噪声干扰。简单的中心裁剪或固定区域裁剪无法自适应不同事件发生的空间位置。

**（2）均匀抽帧导致的关键时刻信息稀释**

足球关键事件（如射门瞬间、扑救动作）通常持续1-3秒，而视频片段通常为9-10秒。常规均匀抽帧策略将16或32帧均匀分布在整段时间窗口内，导致事件发生关键时刻的帧密度不足，而大量无关时刻的帧却被保留。这造成了时间维度上的信息稀释。

**现有方案缺陷**：均匀抽帧不考虑事件的时间分布特性。对于持续时间短、变化剧烈的关键动作，需要在事件窗口内进行更高密度的时序采样。

**（3）单一视角特征无法兼顾全局上下文与局部细节**

全局画面提供场地布局、球员站位等上下文信息，但缺乏事件发生区域的细节；局部裁剪画面提供球、球门、球员动作等细节信息，但丢失了全局空间关系。单一视角处理无法同时利用两种互补信息。

**现有方案缺陷**：简单特征拼接或平均融合无法根据ROI质量动态调节两个分支的贡献比例。当检测器输出不可靠时（如球被遮挡、球门检测失败），基于低质量ROI的局部特征反而会损害分类精度。

### 2.3 本发明要解决的技术问题

1. 如何在远景广角足球视频中自动定位并聚焦于事件发生的关键空间区域；
2. 如何在长视频片段中实现事件感知的自适应时序采样；
3. 如何有效融合全局上下文信息与局部细节信息，并在ROI质量不可靠时安全回退；
4. 如何在球、球门等目标极小（球仅3-5像素）的条件下实现鲁棒的ROI候选评分与选择。

---

## 三、发明内容

### 3.1 技术方案概述

本发明提出一种**检测感知空间裁剪 + 自适应时序采样 + 双分支门控融合**的足球关键事件检测框架，核心包括四个技术模块：

- **模块A**：基于预计算检测索引的多锚点ROI（Region of Interest，感兴趣区域）生成与优先回落机制
- **模块B**：事件中心化自适应时序窗口采样策略
- **模块C**：全局-局部双分支架构与ROI质量感知类级门控融合
- **模块D**：面向极小目标的鲁棒多线索候选评分方法

### 3.2 模块A：多锚点ROI生成与优先回落机制（核心创新点1）

#### 3.2.1 预计算紧凑检测索引（离线阶段）

为解耦目标检测与模型训练/推理，本发明采用离线-在线两阶段设计：

- **离线阶段**：对每段视频以固定采样率（如2fps）运行目标检测与多目标跟踪，检测类别包括：人（class=0）、球（class=1）、球门（class=2）、中圈（class=3）。检测结果原始为每帧JSON格式（单视频可达400-900MB）。

- **索引构建**：将原始检测结果转换为紧凑的`.pt`二进制索引文件，包含：
  - 采样帧ID数组及其偏移量
  - 按类别分组的边界框、置信度、轨迹ID
  - 球轨迹专用数据：球轨迹偏移量、逐点帧ID、逐点边界框、球点触碰标志、球轨迹触碰标志
  - 检测分辨率与帧率元数据
  - 版本号（v2）

该紧凑索引将数百MB的JSON压缩至数MB的单个`.pt`文件，支持DataLoader多进程高效随机读取，且索引与训练/推理解耦，索引构建一次后可被所有实验复用。

#### 3.2.2 在线ROI提案生成（训练/推理时）

对于给定的时序窗口 `[start_sec, end_sec]`，在线实时生成ROI提案：

**步骤1：时间窗口内检测数据检索**

根据窗口起止时间转换为帧号范围，通过偏移量数组快速定位时间窗口内的所有检测对象，避免全量扫描。

**步骤2：候选聚类与评分**

使用基于几何距离和轨迹一致性的增量聚类算法对球门、中圈检测进行分组。聚类条件综合考虑：
- 几何邻近性（中心距离 ≤ 0.055倍对角线长度，尺寸对数差 ≤ 0.85）
- IoU重叠度（≥ 0.12）
- 轨迹一致性（同一轨迹ID且中心距离 ≤ 0.12，尺寸差 ≤ 1.50）

每个候选的综合得分融合以下维度（详见模块D）：
- 时序持续性（persistence）
- 检测置信度中位数（median_confidence）
- 中心位置稳定性（center_stability）
- 尺寸稳定性（size_stability）
- 形状一致性（IoU稳定性）
- 轨迹一致性（track_consistency）

球候选额外评估：
- 运动连续性（方向一致性 × 0.55 + 加速度平滑性 × 0.45）
- 尺度稳定性
- 与人体的空间邻近性
- 缺口容忍度（gap_score）
- 检测支撑比例（detection_support）

**步骤3：球门-球联合选择与互校验**

球门和球的选择不是独立的，而是互相校验：
- 先独立评分球门候选和球候选
- 球门选择时以球位置为参考：与球距离越近的球门得分上调（权重0.15）
- 球选择时以球门为参考：与球门距离越近的球得分上调（权重0.15）
- 若选出的球与已选球门不一致，重新以新球为参考选择球门（joint optimization）
- 当球门和球的空间距离过远（归一化距离 > 0.80），弱化得分较低的一方（×0.5）

**步骤4：四模式ROI锚点分配与优先回落**

根据球门和球的置信度组合，分配ROI模式（按优先级）：

| 模式 | 条件 | 锚点 | 说明 |
|------|------|------|------|
| `goal_ball` | goal_score ≥ 0.45 ∧ ball_score ≥ 0.35 | [球门, 球] | 同时包含球门和球，最优模式 |
| `goal_players` | goal_score ≥ 0.50 | [球门] | 仅球门可靠，适用于射门后等场景 |
| `ball_players` | ball_score ≥ 0.40 | [球] | 仅球可靠，适用于中场推进等场景 |
| `center_circle_players` | cc_score ≥ 0.55 | [中圈] | 仅中圈可靠，适用于开球等场景 |

当 `goal_ball` 模式因面积过大无法生成有效ROI时，自动回落至 `ball_players`（优先保留球信息，因为球位置与事件时刻关联更直接），再回落至 `goal_players`。

**步骤5：附近球员筛选与排序**

基于锚点位置筛选附近的稳定球员：
- 对球员检测结果按2帧最小持续性进行候选聚类
- 按与锚点中心的加权注意力得分排序（锚点邻近度 × 0.40 + 人群密度 × 0.35 + 时序持续性 × 0.15 + 候选得分 × 0.10）
- 最多保留 `max_people`（默认10）个球员

**步骤6：整数倍约束ROI拟合**

最终ROI边界框需满足以下约束：
- 宽度和高度均为模型输入尺寸（如384×640）的整数倍
- 满足最小/最大面积比约束（min_crop_area_ratio ≤ area_ratio ≤ max_crop_area_ratio）
- 完全位于源帧内
- 包含所有锚点边界框 + padding（默认15%）

若当前球员集合导致ROI过大，按优先级从低到高逐人移除，优先保留锚点。

**步骤7：ROI置信度计算**

按模式计算综合置信度：
- `goal_ball`：0.45 × goal_score + 0.45 × ball_score + 0.10 × person_support
- 其他模式：0.75 × anchor_score + 0.25 × person_support（上限截断）

置信度低于 `min_roi_confidence`（默认0.40）的提案标记为无效。

#### 3.2.3 训练时ROI噪声增强

为提高模型对检测器失效的鲁棒性，训练时对ROI提案施加随机噪声：

- **强制无效**（概率0.15）：将有效ROI强制置为无效，模拟检测器完全失效
- **球门/球丢弃**（各概率0.10）：随机丢弃球门或球锚点，模拟单锚点缺失
- **孤立误检**（概率0.05）：将ROI平移到随机位置并清零所有语义得分，模拟检测器误检
- **中心抖动**（jitter 0.08）：在ROI中心附近随机偏移
- **尺度缩放**：在整数倍约束下随机调整ROI尺度

### 3.3 模块B：事件中心化自适应时序窗口采样（核心创新点2）

#### 3.3.1 正样本采样策略（基于事件锚点）

传统方法从长视频中均匀滑动窗口采样。本发明以人工标注的足球关键事件的**锚点时间**（事件起止时间的中点）为核心，生成训练窗口：

**训练时（temporal jitter）**：
- 窗口长度固定为 `clip_duration` 秒（默认10秒）
- 窗口起始时间的采样范围为：
  ```
  start ∈ [anchor_time - clip_duration + event_margin, anchor_time - event_margin]
  ```
- 即窗口必定包含事件锚点，且锚点距窗口起止至少 `event_margin` 秒（默认1.0秒），确保关键上下文不被截断
- 在合法范围内随机采样起始时间，实现时序数据增强
- `temporal_jitter_sec`（默认1.5秒）控制起始时间的随机扰动幅度

**验证时**：
- 窗口以事件锚点为中心确定性地放置：`start = anchor_time - clip_duration / 2`

**技术效果**：训练时每个事件锚点可产生多个不同时序位置的窗口（通过jitter），既增加了有效训练样本的多样性，又确保事件始终在窗口内且在安全边距内。

#### 3.3.2 负样本采样策略

- 从长视频中不含任何关键事件锚点的时间段随机采样
- 默认负正比例 `negative_ratio = 2.0`
- 负样本支持每视频固定数量（`negative_per_video`）或比例模式
- 可选要求视频包含所有标签类才采样负样本（`negative_require_all_labels`）
- 训练时负样本也施加temporal jitter以提高多样性

#### 3.3.3 困难负样本挖掘

- 在训练集视频上运行密集滑动窗口评估（5秒步长）
- 识别高置信度误检窗口（模型预测为阳性但窗口内无任何GT事件）
- 经过安全边距（2秒）校验和去重（5秒间隔）后，将困难负样本补充到训练集中
- 训练前重新校验挖掘的窗口，防止因标注修复导致的正负标签污染

#### 3.3.4 帧级均匀随机采样

在确定时序窗口后，帧级采样采用分段随机策略：
- 将窗口内的总帧数均匀分为 `num_frames` 个区间
- 在每个区间内随机选择1帧（训练时）或取中心帧（验证时）
- 当窗口内帧数不足时，退化为均匀插值

该策略在保持时间覆盖均匀性的同时引入帧级随机性。

### 3.4 模块C：全局-局部双分支架构与ROI质量感知类级门控融合（核心创新点3）

#### 3.4.1 双分支架构

模型包含两个并行的特征提取与分类分支：

**全局分支（Global Branch）**：
- 输入：全帧画面缩放到 `global_image_size`（如192×320低分辨率）
- 功能：提取全局上下文特征（场地布局、球员站位、比赛态势）
- 训练策略：从预训练模型初始化后冻结（`freeze_global_branch=True`），保持baseline精度

**局部分支（Local/ROI Branch）**：
- 输入：ROI裁剪区域缩放到 `video.image_size`（如384×640高分辨率）
- 功能：提取事件区域的细节特征（球、球门、球员动作）
- 训练策略：从全局分支权重复制初始化后训练

每个分支的结构为：
```
DINOv3 ViT-L → [CLS + PatchMean] concat → frame_proj (LN→Linear→GELU→Dropout)
→ TemporalTransformer (learnable CLS + position embedding + 4-layer Transformer)
→ Classification Head (LN→Linear→GELU→Dropout→Linear)
```

#### 3.4.2 ROI元数据向量编码

将ROI提案的结构化信息编码为16维元数据向量，作为门控网络的额外条件输入：

| 维度范围 | 内容 | 说明 |
|----------|------|------|
| [0] | ROI有效性 | 0/1标志 |
| [1] | ROI置信度 | 综合置信度得分 |
| [2] | 面积比 | ROI占原图比例 |
| [3] | 球门得分 | goal_score |
| [4] | 球得分 | ball_score |
| [5] | 中圈得分 | center_circle_score |
| [6] | 球员支撑度 | person_support |
| [7:11] | ROI模式one-hot | goal_ball / goal_players / ball_players / center_circle_players |
| [11:16] | 回落原因分组one-hot | ok / train_augmented / low_confidence / area_invalid / missing_or_no_anchor |

#### 3.4.3 类级可学习门控融合

门控网络结构：
```
Gate([global_temporal; local_temporal; roi_meta]) = 
    LN → Linear(hidden_dim*2+roi_meta_dim, hidden_dim/4) → GELU → Linear(hidden_dim/4, num_labels) → Sigmoid
```

- 输入：全局时序特征 ⊕ 局部时序特征 ⊕ ROI元数据向量
- 输出：每个事件类别独立的门控权重 α ∈ [0, 1]^num_labels
- 初始化策略：最后一层权重初始化为0，偏置初始化为-3.0（Sigmoid(-3) ≈ 0.047），使初始融合接近纯全局预测

**融合公式**：
```
logits = global_logits + α * confidence * roi_valid * (local_logits - global_logits)
```

其中：
- `α` 为可学习门控权重
- `confidence` 为ROI置信度（硬约束）
- `roi_valid` 为ROI有效性标志（0/1，硬约束）

**关键特性**：
1. **类级独立调节**：不同事件类别可以有不同的门控权重（如射门可能更依赖局部细节，角球可能更依赖全局布局）
2. **无效ROI安全回退**：当ROI无效时（`roi_valid=0`），`α=0`，输出完全退化为全局分支预测，不会因低质量ROI降低精度
3. **凸组合保证**：融合输出始终在全局和局部预测之间，避免极端偏移
4. **置信度调制**：即使ROI有效，置信度低时也会降低局部特征的贡献

#### 3.4.4 训练损失函数

```
L_total = BCE(fused_logits, labels) + local_loss_weight * BCE(local_logits, labels)
```

- 主损失：融合预测与真实标签的BCE损失
- 辅助损失：局部预测与真实标签的BCE损失（权重0.30），引导局部支路学习有效的ROI特征
- 全局分支冻结，仅训练局部分支和门控网络

### 3.5 模块D：面向极小目标的鲁棒多线索候选评分（核心创新点4）

#### 3.5.1 球轨迹候选评分

球在远景画面中通常仅3-5像素，单帧检测噪声极大。本发明利用时间维度信息对球轨迹进行多线索评分：

**评分维度（以权重排序）**：
1. **时序持续性**（0.18）：轨迹在时间窗口内的持续时间（归一化到1秒标准）
2. **形态合理性**（0.16）：检测框面积比（median_area_ratio）是否在合理范围 [1e-6, 2e-3]，宽高比是否在 [0.35, 2.85]
3. **检测支撑度**（0.12）：球轨迹点与低置信度（0.10）原始检测点的一致性比例
4. **运动连续性**（0.14）：综合方向一致性（相邻速度向量的余弦相似度中位数）和加速度平滑性
5. **时序缺口惩罚**（0.14）：轨迹中最大时间间隙的指数衰减惩罚 `exp(-max_gap/0.5)`
6. **人体邻近性**（0.12）：球与最近球员的最小距离的指数衰减 `exp(-min_dist/(0.08*diagonal))`
7. **尺度稳定性**（0.08）：检测框面积对数标准差的指数衰减
8. **触碰标志**（0.06）：是否有任何检测点或轨迹被标记为球被触碰

形态不合理且无触碰标志的候选评分乘以0.25的惩罚系数。

**最佳短间隙段选择**：在球轨迹中可能存在因遮挡导致的检测间隙。本发明选择包含最多可信检测点的连续短间隙段（间隙 ≤ 0.5秒），并将远离可信点的检测排除，避免遮挡前后的漂移点污染轨迹。

#### 3.5.2 球门/中圈候选评分

**评分维度**：
1. **时序持续性**（0.25）：检测在多少独特帧中出现（相对于最小帧数×2归一化）
2. **中位置信度**（0.22）：检测置信度的中位数
3. **中心稳定性**（0.18）：检测中心位置的标准差的指数衰减
4. **尺寸稳定性**（0.15）：检测面积对数标准差的指数衰减
5. **形状一致性**（0.12）：各检测框与代表框的IoU中位数
6. **轨迹一致性**（0.08）：同一轨迹ID在聚类中的主导程度

使用鲁棒分位数框（10%-90%分位数）作为聚类代表框，抵抗离群检测框的干扰。

#### 3.5.3 球门-中圈角度排除

利用足球场的几何约束：球门line不应与中圈在同一垂直方向。当候选球门与高置信中圈的水平偏移角 < 60° 或水平距离小于中圈宽度一半时，该球门候选得分乘以0.15的惩罚，有效排除误将中圈标识为球门的错误。

## 四、技术效果与实验验证

### 4.1 实验设置

- **模型**：DINOv3 ViT-L/16，LVD-1689M预训练 + LoRA微调（rank=8，后4层attention）
- **标签体系**：set_piece（射门/扑救/定位球三类）
- **数据**：47训练视频 + 11验证视频（detector-covered）
- **评估协议**：10秒窗口、5秒步长、point-NMS 5秒、匹配容差5秒

### 4.2 ROI质量（模块A+D效果）

| 指标 | 数值 |
|------|------|
| 高置信ROI人工正确率 | ≥ 90% |
| 有效ROI中位面积比 | ≤ 0.60 |
| 相邻有效ROI中位IoU | ≥ 0.60 |

### 4.3 模型性能对比

| 实验 | 描述 | 预期效果 |
|------|------|----------|
| 全局基线（global-only） | 整帧低分辨率输入 | baseline |
| ROI单视图（exp1） | 仅ROI裁剪输入 | 验证ROI信息增益 |
| 双分支门控（exp2） | 全局+局部+门控融合 | **主方案**：precision提升，recall不降 |
| 精度微调（exp3） | exp2 + 高负样本比微调 | 条件优化 |

### 4.4 关键创新点的技术优势总结

1. **ROI裁剪**：将球、球门等极小目标的像素占比提升10-50倍（从原图的0.01%-0.1%提升到裁剪后的1%-5%），使DINOv3 ViT能够有效提取判别特征
2. **事件中心化采样**：确保关键时刻在训练窗口内的帧密度最大化，相比均匀滑动窗口采样提升了正样本的信息密度
3. **双分支门控融合**：全局精度不降的前提下提升precision，无效ROI时安全回退
4. **多线索评分**：在球仅3-5像素的极端条件下实现鲁棒的ROI定位

## 五、权利要求建议

### 独立权利要求1（方法）

一种基于检测感知空间裁剪的足球视频关键事件检测方法，其特征在于，包括以下步骤：

**S1. 紧凑检测索引构建步骤**：对视频以固定帧率运行目标检测与跟踪，将原始逐帧检测结果压缩为包含帧偏移量、分类边界框、置信度、轨迹ID及球轨迹专用数据的结构化二进制索引文件；

**S2. 多锚点ROI提案生成步骤**：对于给定的时序窗口，从所述紧凑检测索引中检索窗口内的检测对象；对球门、中圈、球分别进行基于几何距离与轨迹一致性的候选聚类与多维度评分；通过球门与球的互校验联合选择确定最优锚点组合；根据锚点置信度分配ROI模式并生成包含语义锚点和附近稳定球员的ROI边界框；

**S3. ROI约束拟合步骤**：将ROI边界框拟合为模型输入尺寸的整数倍，满足面积比约束和帧内包含约束，当球员过多导致ROI过大时按优先级逐人移除；

**S4. 事件中心化时序采样步骤**：以人工标注事件的锚点时间为中心，在保证事件锚点距窗口起止至少预定安全边距的约束下随机采样时序窗口起止时间；

**S5. 双分支特征提取与门控融合步骤**：对全局画面和ROI裁剪区域分别提取视觉特征，经时序融合后，通过以全局特征、局部特征和ROI元数据向量为条件的类级可学习门控网络生成融合预测结果。

### 独立权利要求2（系统）

一种基于检测感知空间裁剪的足球视频关键事件检测系统，包括：紧凑检测索引构建模块、多锚点ROI提案生成模块、ROI约束拟合模块、事件中心化时序采样模块、以及双分支门控融合分类模块，各模块执行权利要求1所述方法中的对应步骤。

### 从属权利要求（部分示例）

- 所述多锚点ROI提案生成步骤中，ROI模式按优先级包括：球门-球联合模式、球门-球员模式、球-球员模式、中圈-球员模式，当高优先级模式无法生成有效ROI时自动回落至下一优先级。
- 所述球门与球的互校验联合选择步骤包括：先独立评分候选，再以球位置调整球门得分，以球门位置调整球得分，当两者空间距离过大时弱化低分方。
- 所述双分支门控融合步骤中，融合公式为 `logits = global_logits + α * confidence * roi_valid * (local_logits - global_logits)`，其中α为可学习类级门控权重，confidence为ROI置信度，roi_valid为ROI有效性标志，无效ROI时融合输出自动退化为全局预测。
- 所述球候选评分包括：时序持续性、形态合理性（面积比和宽高比范围约束）、检测支撑度（与低置信度原始检测的一致性）、运动连续性（方向一致性和加速度平滑性）、人体邻近性、尺度稳定性、时序缺口惩罚和触碰标志共8个维度的加权融合。
- 训练时对ROI提案施加噪声增强，包括：以预定概率强制置为无效、随机丢弃球门或球锚点、将有效ROI平移至随机位置并清零语义得分、ROI中心随机抖动。
- 所述紧凑检测索引包含球轨迹触碰标志（球点触碰和球轨迹触碰），用于辅助球候选评分的可靠性判断。

## 七、与现有技术的区别

| 对比维度 | 现有技术 | 本发明 |
|----------|----------|--------|
| 空间处理 | 整帧均匀缩放或固定区域裁剪 | 检测感知的语义锚点多模式ROI裁剪，带优先回落 |
| 时序采样 | 均匀滑动窗口或均匀抽帧 | 事件锚点中心化采样，安全边距约束，temporal jitter增强 |
| 多视角融合 | 简单拼接/平均 | 类级可学习门控，ROI元数据条件化，无效时安全回退 |
| 小目标处理 | 依赖检测器置信度 | 8维球评分 + 6维球门评分的多线索鲁棒评分，轨迹级优化 |
| 检测-训练耦合 | 训练时实时检测或离线固定裁剪 | 紧凑索引解耦：一次构建，多次复用，支持训练时ROI增强 |
| ROI质量 | 二元有效/无效 | 连续置信度 + 元数据编码，门控网络自适应调节融合权重 |
