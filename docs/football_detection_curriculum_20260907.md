# 检测定位到事件理解的两阶段实验

状态：2026-09-07 设计稿，响应用户提出的课程学习思路；尚未实现或启动训练。基于已完成 B1、自动轨迹对照及现有 ROI/motion 模块。

## 核心假设

先让足球域适配特征可靠定位球/球门，再让预测位置选择局部视觉 token，帮助事件时序分支。区别于 B1 的外部几何投影：新方案验证检测监督改变局部表征、局部表征是否有事件增量两个独立问题。

“微调后特征完全不变”与“改变特征以增强定位”无法同时严格满足。可保证原始通路冻结并可恢复；适配通路用正则限制漂移，但不能保证其所有通用能力不变。冻结基础权重仅训练 LoRA 也会改变激活。

## 结构

使用当前 E16 作为事件锚点，冻结其完整 RGB/事件通路。检测分支从相同特征来源初始化，用独立 LoRA/adapter，不能复用并更新 E16 当前事件 adapter。第一轮不将检测适配权重直接覆盖主干。

原版 DINO 与 E16 是不同参照：若检测分支从 E16 开始，特征保持教师应先用冻结 E16 对应层；若另以原版 DINO 为教师，应单列对照，不能把它称作完全保持 E16。E16 事件输出和特征保真分别监控。

实现独立最后若干层的适配时，可共享完全冻结的前缀计算，但分叉后的 token 必须分别计算；同一活跃 LoRA 输出同时喂两条路径不能保证锚点不变。需要测量实际显存/算力，不能假定双分支无成本。

## 第一阶段：定位能力和特征保持

1. 冻结特征，训练同一个轻量 ball/goal heatmap 头，建立定位读出基线。它本身不算 DINO 特征微调。
2. 若冻结读出不足，再启用独立检测 adapter。以最后少量 block、低秩 LoRA 为起点，其他权重冻结；具体层数、秩和学习率是待锁定超参数，不是已验证最优值。
3. 检测损失只在可信标注区域计算：已确认对象为正，人审确认无对象为负，其他未知；伪标签漏检不能自动当负。检测置信度用于样本权重，不把低置信球目标简单压成低幅度响应。输入增强对 RGB、坐标、mask 和教师特征严格同步。
4. 冻结教师约束全局 token 与抽样 patch 的特征漂移。目标邻域可降低保持权重以允许学习，但保留非零约束；背景不应压倒小球监督。可先使用归一化特征余弦损失，若局部关系结构明显退化，再单独比较 patch Gram 关系约束，避免首轮堆叠所有损失。

建议起始目标：L = L_loc + λ_global L_global_feature + λ_patch L_patch_feature。λ 按检测收益/保真曲线选择；不能用任意 λ 声称语义保持。Gram 约束受 DINOv3 的 dense feature 保护思路启发，是本实验迁移设计而非原论文对足球微调的结论。

从清晰可见、时间精确、身份连续的同源样本开始，再加入小球、模糊、遮挡和困难背景；保持随机训练帧及困难例回放，避免后期或验证只看检测器容易检出的样本。异源检测标注可选作训练补充，不是前置条件；验收必须有比赛隔离的同源人工核查子集，全部未见帧也需要统计。

阶段验收：在同一人工核查集合上比较冻结读出与适配读出，报告中心误差、明确阈值下定位召回/精度、ROI 是否覆盖球、每图误报、小目标/遮挡分层。球门若仅用中心 heatmap 不应冒称框检测 AP。记录教师特征相似度/关系漂移及冻结 E16 数值不变。不可用热图更亮、伪标签训练 hit rate、单一 CLS 相似度证明成功。

固定 patch16 特征上的 heatmap 上采样不等于新增图像细节；当球比 patch 小很多，先看原图 crop 是否带来定位收益，不能单靠更尖的热图解决。

## 第二阶段：预测定位引导局部视觉时序

先冻结第一阶段的检测分支与定位头，detach 位置/路由权重；只训练独立局部事件时序分支及融合。这样事件损失暂时不能把定位热图改成分类捷径。最后是否联合微调另作实验。

优先方案是 soft heatmap 路由加局部邻域 token：多个候选峰各取小邻域，保留局部 appearance、坐标、时间、可用性和全局/人动作上下文。soft pooling 提供稳定起点；若过度平均，再比较候选局部 token。球门独立低分辨率上下文，不与球争用同一 top-k 名额。

不建议首轮把全局 patch 直接乘 heatmap 后替换主路径；背景动作和身体信息可能被削弱。固定 top-k 在无球时也会强制选择噪声，要有质量门、null token；逐帧位置跳变要记录多候选/时间连续性，不能把每帧第一名默认成同一对象。球附近邻域必须足够容纳脚部、上身或门将动作，孤立球像素无法区分射门/传球或扑救/接回传。

ROIAlign 从原特征图取局部信息，无新增像素细节；原图 crop 再编码才可能恢复小球细节，但增加计算并需处理裁剪抖动。仅当阶段一诊断确认细节不足再做该比较，所有对照匹配帧数和预算。

第一轮用独立事件残差融合，并保留 E16 全局输出：z_c = z_E16,c + g_c Δz_local,c。零门控可恢复基线，需检查门控和投影梯度，避免再次出现分支未生效；零门控本身不保证训练后不退化。类别独立选型，不能因定位球有效就默认射门/扑救都开同样强度。

训练和验证均让学生预测 heatmap 参与路由，人工/检测教师只用于监督或单独诊断；不能以真值框路由成绩充当部署效果。长视频使用相同扫描窗口，不因 detector 无输出就删除候选。若最终仍要求无外部检测器推理，学生必须自己预测位置。

## 必要对照

| 组 | 特征与定位 | 事件局部路由 | 目的 |
|---|---|---|---|
| E0 | E16 | 无新增支路 | 原工作点 |
| E1 | 冻结特征 | 同预算普通局部/可学习 query，不用检测监督 | 容量与局部时序收益 |
| E2 | 冻结特征 + 定位头 | 预测 heatmap | 检测引导选择是否有用 |
| E3 | 第一阶段适配特征 + 定位头 | 相同预测 heatmap 结构 | 检测特征微调是否比 E2 有增量 |

E1/E2/E3 匹配局部 token 数、时序容量、帧数、训练数据和融合规则。E3 与 E2 若同时改变特征和定位，所得是两阶段方案整体增量；若需分离原因，缓存同一 heatmap 交叉使用冻结/适配 appearance，再做小型诊断，不在首轮铺开全部组合。

失败后动作：阶段一定位不优于冻结读出，先解决监督和小球分辨率，不进入更大事件训练；E2 优于 E1 但 E3 不优于 E2，采用冻结特征定位即可；E3 定位更准却事件无增益，说明定位仍未补足动作信息，转向交互时间监督和难负例，而非继续提升 heatmap。

事件验收：校准视频定阈后固定，未用于选型的视频报告实际 R、P、FP/小时、定位误差、逐比赛变化及区间；射门/扑救/定位球最低 R 沿用 85%/80%/80%。候选目标是同召回下降低误报，不能以窗口 AP 单独替代。当前内部 val 已参与多轮选择，结果只能用于开发，不声称盲测。
